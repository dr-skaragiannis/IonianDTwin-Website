# IonianDTwin — deployment for `ioniandtwin.di.ionio.gr`

## Single source folder: `public/`

`public/` is the only authoritative site folder (Vite's static source root, committed).
`dist/` is a transient build output only — it is gitignored and regenerated by
`npm run build`, and the built `index.html` is synced back into `public/` by
`npm run deploy:public`. Deploy from `public/`; never edit or commit `dist/`.

## What `npm run deploy:public` produces in `public/`

| File(s) | Purpose |
|---|---|
| `index.html` (~870 KB, ~250 KB gzip) | Interactive single-file SPA (home `/`) |
| `<route>/index.html` × 15 | Static SEO shells with route-specific title/meta/OG/JSON-LD + bilingual summary; capable browsers auto-continue to the live app at the same clean URL |
| `404.html` | Styled not-found page; auto-routes known app paths to the SPA |
| `robots.txt`, `sitemap.xml` | Crawler rules + 16 canonical URLs |
| `og-image-el.jpg` (1810×922), `og-image-en.jpg` (1775×966) | Social share cards (Greek default + English alternate) |
| `favicon.svg`, `favicon-32x32.png`, `favicon-16x16.png`, `apple-touch-icon.png`, `icon-512.png`, `site.webmanifest` | Icons / PWA |
| `images/*.jpg` × 3 | Hero, crowd, sensor photos (separate cacheable files, not inlined) |
| `.htaccess` | Apache: `/404.html` handler, compression, cache + security headers (ignored elsewhere) |

## Deploy

Copy the **entire `public/` folder contents** (not just `index.html`) to the web root of
`ioniandtwin.di.ionio.gr`, preserving subdirectories. No server rewrites required:
every sitemap URL maps to a real `index.html` on disk.

After deployment, verify:

- `https://ioniandtwin.di.ionio.gr/robots.txt` and `/sitemap.xml` return 200
- `https://ioniandtwin.di.ionio.gr/indicators/` shows the static summary, then opens the app
- Share `https://ioniandtwin.di.ionio.gr/` on Teams/Facebook — the OG card should render
- Submit the sitemap in Google Search Console

## Regenerating static assets (sources live in `public/` + `scripts/`)

```bash
node scripts/make-images.mjs          # favicon PNGs from public/favicon.svg (needs: npm i -D sharp)
node scripts/generate-route-shells.mjs # 15 route shells + 404.html from route metadata
npm run build                          # copies public/ → dist/ and bundles the SPA
```

Edit route titles/descriptions in `scripts/generate-route-shells.mjs`, re-run it,
then rebuild. `sitemap.xml` lastmod should be bumped on content updates.
